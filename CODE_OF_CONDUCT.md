# Code of Conduct

## Our pledge

We want Compliance DVN to be a focused, respectful, and technically rigorous open
source project. Everyone participating in issues, pull requests, reviews,
Discussions, and other project spaces is expected to help keep the environment
welcoming and productive.

## Expected behavior

- Be respectful and constructive, especially when disagreeing.
- Focus technical criticism on code, design, tests, documentation, and risk.
- Assume good intent, but ask for clarification when something is ambiguous.
- Accept maintainers' decisions once a discussion has been resolved.
- Credit the work and ideas of others.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Sexualized language or imagery.
- Trolling, sustained disruption, or bad-faith participation.
- Publishing private information, secrets, or security reports without permission.
- Any behavior that would reasonably make participation unsafe or unwelcome.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict
participation when behavior violates this code of conduct. Enforcement decisions
will be based on the impact on the project and its contributors.

If you need to report conduct concerns, contact the maintainers privately. For
security vulnerabilities, use the separate process in [SECURITY.md](./SECURITY.md).
